# rad.ar Product Branding

Spec 6001 makes `rad.ar` the canonical user-facing project name across current
documentation, descriptive metadata, API/MCP presentation, watcher logs, and
Discord notifications.

This is deliberately not a breaking identifier migration. Existing
`@ever-jobs/*` imports, `EVER_JOBS_*` environment variables, `ever_jobs_*`
metrics, CLI/MCP identifiers, API routes, Docker service names, and deployment
resources remain supported under their current names.

Historical specs, logs, changelogs, probe evidence, and generated plugin notes
retain their original wording. See the authoritative
[spec](../../.specify/specs/6001-rad-ar-branding/spec.md),
[plan](../../.specify/specs/6001-rad-ar-branding/plan.md), and
[tasks](../../.specify/specs/6001-rad-ar-branding/tasks.md).
